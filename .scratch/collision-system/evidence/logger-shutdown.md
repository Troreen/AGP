# Diagnostic shutdown repair

The full sphere suite first reached all assertions and printed PASS with std::endl, then failed to terminate with only main/Logger worker threads alive and negligible CPU. Exact test processes were stopped for continuation. Logger::Timestamp lazily initialized two static std::strings on its worker; this can contend with CRT static teardown and their destruction can race pending log work. Under root authorization these three format uses were replaced with constexpr literal pointers. The identical test suite then exited zero with production GFLOG diagnostics still enabled. No sleep, verbosity suppression, Logger lifecycle redesign, or gameplay changes were used. See 02-lifecycle-build/run.log and 03-final-debug-build/run.log for subsequent successful runs.

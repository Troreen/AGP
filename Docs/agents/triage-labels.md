# Triage roles

These strings go on a local issue's `Status:` line.

| Role | Meaning |
| --- | --- |
| `needs-triage` | Needs evaluation and scope decisions. |
| `needs-info` | A required answer is missing. |
| `ready-for-agent` | Specified and ready to implement once blockers resolve. |
| `ready-for-human` | Requires human implementation. |
| `wontfix` | Deliberately declined. |

Implementation additionally uses `in-progress` and `resolved`, as described in [issue-tracker.md](issue-tracker.md).
